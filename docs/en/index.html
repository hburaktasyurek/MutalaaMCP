What it does

Take a shorter path to the Turkish legal source you need.

MutalaaMCP is not another AI app. It adds legal-research tools to the app you already use.

01

Search decisions and legislation

Search court decisions, legislation, and Constitutional Court decisions without leaving the conversation.

02

Find the relevant text

Go directly to the article or section you need inside a long piece of legislation.

03

Check the source too

“That’s just how it is” is not enough. Open the document behind the answer at its official address and check important information instead of relying on a summary.

How to use it

Install, connect, and start researching.

Install a published version using the terminal guide, then sign in to Mütalaa from your app.

  1. 1

    Install the package

    Run the uv command in the setup guide. uv manages the Python environment.

  2. 2

    Connect your app

    Set up the local MCP service and add the guide’s URL to your app’s MCP settings.

  3. 3

    Sign in with Mütalaa

    Select Authenticate in your app, then complete account sign-in and device approval in the browser.

  4. 4

    Ask your first question

    Add the Mütalaa skill and start a new conversation. Check the tool calls to confirm Mütalaa was used.

Common questions

Short, direct answers.

Can I install it today?

Yes. The installation guide uses the GitHub release package. uv prepares the required Python environment.

Does it cost anything?

Local MutalaaMCP use is free and open source. The AI app you use may have its own separate fees.

Does it work with ChatGPT Desktop?

It depends on your app version and account. The guide walks through in-app sign-in for desktop versions that support it; a remote-only connection screen cannot use this local address.

Does my research stay entirely offline?

No. The tool runs on your computer, but it reaches official sources over the internet to find decisions and legislation.
